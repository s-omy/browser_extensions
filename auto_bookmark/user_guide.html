📑 ブックマーク整理 by Gemini

ページを開いてワンクリック。AI が最適なフォルダに仕分けます。

増えすぎたブックマークを、AI の力で自動的に仕分ける拡張機能です。既定では Google の「Gemini」を直接使いますが、設定で LiteLLM Proxy などの別のエンドポイント（自分で用意したものを含む）に切り替えることもできます。どちらの場合も、中継サーバーは介しません。

⚠️ 先にお読みください（データの送信と費用）
  • 仕分けの判定のため、ページのタイトル・URL・ページの概要（meta 情報）などが、設定した AI プロバイダへ送信されます。既定は Google の Gemini API です。送りたくないページは、プライバシー設定で除外できます。
  • API キーは、この端末のブラウザ内に暗号化されずに保存されます。共有パソコンでは使わないでください。
  • API の利用には、料金や利用上限がかかる場合があります。最新の条件は、利用先（Google など）の案内でご確認ください。このガイドの 費用の目安と節約 も参照してください。

🚀 1. インストール

1拡張機能のフォルダを用意

配布されたフォルダ（manifest.json や background.js などが入っているフォルダ全体）を、パソコンの分かりやすい場所に置きます。中のファイルは動かさないでください。

2デベロッパー モードをオン

Chrome のアドレス欄に chrome://extensions/ と入力して開き、画面の右上にある「デベロッパー モード」のスイッチをオンにします。

3フォルダを読み込む

左上の「パッケージ化されていない拡張機能を読み込む」を押し、手順1のフォルダを選びます。インストールが終わると、設定画面が自動で開きます。

💡 ツールバーにアイコンを出しておくと便利です。Chrome 右上のパズルのアイコンから、この拡張機能の「ピン留め」を押してください。

🔑 2. AIプロバイダとAPIキーの用意

設定画面の一番上「AI プロバイダ」で、どちらを使うか選びます。ほとんどの方は Gemini（既定のまま）で問題ありません。

Gemini を使う場合（既定）

  1. Google AI Studio を開き、Google アカウントでログインして API キーを作成します。
  2. 設定画面の「AI プロバイダ」が「Gemini」になっていることを確認し、API キー欄に貼り付けて「設定を保存」を押します。
  3. 「接続テスト」を押して、「接続に成功しました」と出れば準備完了です。
キーは他人に見せないでください。漏れた場合は、Google AI Studio でキーを削除・再作成してください。

LiteLLM Proxy など、別のエンドポイントを使う場合

社内で運用している LiteLLM Proxy や、その他の「OpenAI 互換」なサーバーへ振り分けの判定を任せたいときは、こちらを選びます。自分でサーバーを用意できる方向けの、上級者向けの設定です。

  1. 「AI プロバイダ」で「OpenAI 互換エンドポイント（LiteLLM Proxy 等）」を選びます。「エンドポイントURL」と「モデル名」の欄が現れます。
  2. エンドポイントURLに、そのサーバーのアドレス（例: https://your-litellm-proxy.example.com）を入力します。
  3. モデル名に、そのサーバー側で使いたいモデルの名前（LiteLLM 側で設定したエイリアス等）を入力します。この欄は空欄にできません。
  4. API キー欄に、そのサーバー用のキー（LiteLLM の仮想キーなど）を入力します。
  5. 「設定を保存」を押すと、入力したアドレスへのアクセスを許可するかどうか、Chrome から確認が出ます。「許可」を選ぶと保存されます（拒否すると保存されません）。
  6. 「接続テスト」で疎通を確認してください。
💡 自前でホストしたサーバーだけを使う構成にすれば、ブックマークのデータを Google などの外部へ一切送らずに使うこともできます。ただし、応答の形式に対する対応度はサーバー・モデルによって差があり、Gemini ほど枯れていない場合があります（FAQ参照）。

✅ 3. 最初にやること

AI は、各フォルダの「説明文」を手がかりに振り分け先を選びます。最初に一度、次の順で準備してください。

1APIキーを保存して接続テスト（上記のとおり）

2「① フォルダ解析」を実行：設定画面の「🔄 AIで全フォルダを解析・更新する」を押します。AI が各フォルダの説明文を作ります。これをしないと、AI はフォルダ名だけで判断するため、振り分けの精度が下がります。

3（任意）「③ ナレッジ同期」：一括整理（②）をするときに、判断材料が増えます。右クリックで保存するだけなら不要です。

フォルダを新しく作ったり、中身を大きく入れ替えたりしたときは、「✨ 未解析・変更のあるフォルダだけ解析する」で、必要なフォルダだけ解析し直せます。

🖱️ 4. ふだんの使い方

残したいページを開いた状態で、次のどれかを行います。

操作動作
ページの空いた場所、またはタブを右クリック →「📑ブックマーク」→「最適カテゴリへ追加」AI が最適なフォルダを選んで保存します
ツールバーのアイコンをクリック同じく、AI が選んだフォルダへ保存します
Alt + Shift + B同じく、AI が選んだフォルダへ保存します（割り当てを変えるには chrome://extensions/shortcuts）
右クリック →「📑ブックマーク」→ 好きなフォルダ名AI を使わず、そのフォルダへ保存します（「クイック保存先」。設定画面で選べます）
右クリック →「📑ブックマーク」→「未分類に追加」AI を使わず、「未分類」フォルダへ保存します

保存したあとの通知

保存が終わると、通知に結果が表示されます。仕分けが外れていたときは、通知のボタンでその場でやり直せます（ボタンは環境によっては表示されない、またはすぐ消えることがあります）。

  • 元に戻す：今保存したブックマークを削除します。
  • 「未分類」へ移動：「未分類」フォルダへ移します。

「未分類」に入るのはどんなとき？

AI が自信を持って選べないとき、推測で振り分けず「未分類」に入れます。通知の文面で理由が分かります。

通知の文面意味
「未分類」に追加しました（適合するフォルダなし）AI が「合うフォルダがない」と判断しました
「未分類」に追加しました（確信度が低いため）AI の確信度が 60% 未満でした
AI判定に失敗したため「未分類」に追加しました通信エラー、API キーの問題、AI の応答のブロックなど。理由が通知に表示されます
「未分類」に追加しました（AI判定の対象外）プライバシー設定で送らないと決めたページ（除外ドメイン、http/https 以外のページ）です

「未分類」フォルダが無ければ、ブックマークバーの直下に自動で作られます。

同じページを二度保存したとき

「最適カテゴリへ追加」で、すでにブックマーク済みのページだった場合は、AI を呼ばずに「すでにブックマーク済みです（保存先のフォルダ名）」と知らせます。

💡 ブラウザの内部ページなど、ページの内容を読み取れない場合でも、タイトルと URL から判断して保存します。

🔒 5. 保護フォルダ

[仕事用] のように、フォルダ名を角括弧 [ ] で囲むと保護フォルダになります。その配下のフォルダも保護されます。

  • AI の振り分け先の候補になりません。
  • 一括整理（②）で、中のブックマークを動かしたり、中へ移したりしません（適用の直前にも再確認します）。
  • 中のブックマークのタイトルや URL を、AI に送信しません（フォルダ解析・ナレッジ同期・一括整理のすべて）。

※ 「クイック保存先」に自分で選んだ保護フォルダには、ご自身の操作として保存できます。

⚙️ 6. 設定画面の使い方

設定画面は、拡張機能のアイコンを右クリック →「オプション」、または chrome://extensions/ の「詳細」から開けます。

基本設定（AIプロバイダ・API キー・プライバシー・クイック保存先）

AI プロバイダの選択、API キーの保存と接続テスト、AI に送るデータの制限、右クリックメニューに並べるフォルダ（最大5件）を設定します。

① フォルダコンテキストの解析

AI が各フォルダの説明文を作って記憶します。大きなフォルダは、代表的な30件を選んで AI に見せます。

  • Bookmarkバー：ブックマークバー配下のフォルダの目印です。AI は「日常的に使う大事なフォルダ」として、迷ったときに優先します。
  • 階層は「開発 › Node.js」のように、› でつないで表示します。

② ブックマークの再カテゴライズ（一括整理）

  1. 「🔍 再カテゴライズをシミュレーションする」を押します。件数と API 呼び出し回数の確認が出るので、よければ「OK」を押します。
  2. 結果が「変更差分プレビュー」に出ます。この時点では何も動きません。
    • 移動案ごとに適合率（AI の確信度）と理由が出ます。適合率が 70% 未満の案は、最初はチェックが外れています。
    • 「全選択」「全解除」「適合率が低い項目を外す」、並び順（適合率の低い順）、「変更のある項目のみ表示」で絞り込めます。
    • Unified（1列）と Split（Before/After の2列）の表示を切り替えられます（選択は保持されます）。
    • 「未評価」と出た項目は、通信エラーなどで判定できず、現状維持になったものです。
  3. 移したいものにチェックを付け、「選択した再カテゴライズを実適用する」を押すと、実際に移動します。
  4. 間違えたときは、画面に出る「↩ 元に戻す」で、直前の1回分を元のフォルダ・位置へ戻せます（その後に自分で動かしたブックマークは、そのままにします）。

③ ページコンテキスト（AI 推定ナレッジ）

ブックマークの URL とタイトルから、AI が「テーマ・要約・キーワード」を推定して蓄積します。ページの本文は読んでいないため、あくまで推定です。右クリックで保存したときにページから読み取れた情報は「meta」と表示され、こちらは実際のページの記述です。

  • この画面を開いただけでは、AI を呼びません。「📥 ナレッジベースを同期する」を押したときだけ動きます（件数と回数を確認してから実行します。途中で中止もできます）。
  • キーワードのタグは、「×」で削除、「+ 追加」で自分で追加できます。
  • 削除したブックマークのナレッジは、同期のときに自動で整理されます。

④ 動作ログ

AI との通信の記録です（成功／失敗、失敗の理由、リトライの回数、トークン数）。URL やタイトルは記録しません。うまく動かないときは、まずここを見てください。累計のトークン数から、使った量の目安も分かります。

🛡️ 7. プライバシー設定

設定画面の「基本設定」で、AI に送るデータを絞れます。

設定効果
送信するURLからクエリ文字列とハッシュを取り除く? 以降と # 以降を送りません（ログイン用のトークンなどが URL に含まれる場合に有効）
送信しないドメイン1行に1つ書きます（例: intra.example.co.jp）。そのドメイン（サブドメイン含む）のページは、AI に一切送りません
（常時）http/https 以外のページ（file:、ブラウザ内部ページ、javascript: など）は送りません

AI に送られるものの詳しい一覧は、開発者向けの Readme.md の「プライバシーモデル」にあります。

💰 8. 費用の目安と節約

料金は選んだ AI プロバイダの案内に従います（Gemini なら Google、LiteLLM Proxy 等ならその運用元）。使った量は、設定画面の「④ 動作ログ」の累計トークンで確認できます（一部のプロキシではトークン数が記録されないことがあります）。

操作AI への問い合わせ回数の目安
右クリックなどで1件保存最大 2 回
① 全フォルダ解析フォルダ8個ごとに 2 回
② 一括整理ブックマーク30件ごとに 2 回（最初に回数を表示し、確認してから実行）
③ ナレッジ同期ブックマーク20件ごとに 1 回（新規・期限切れ分のみ。確認してから実行）
  • ②は、ブックマークが多いほど回数が増えます。まずは確認画面の回数をご覧ください。
  • 一括整理をしなくても、右クリック保存だけで使えます。③も任意です。
  • 一度取得したナレッジは、保存済みの分をやり直しません（30日たつと更新の対象になります）。

📌 9. できないこと・注意点

  • 一括整理（②）とフォルダ解析（①）の対象は、フォルダの直下にあるブックマークです。ブックマークバーやその他のブックマークの直下に置いたブックマーク自体は動かしません。
  • 「元に戻す」は、直前の一括適用の1回分だけです。
  • ナレッジは推定です。間違っていることがあります。
  • AI の判断は完璧ではありません。一括整理では、必ず差分プレビューを確認してから適用してください。
  • Chrome 用です。他のブラウザでは動作を確認していません。

🩺 10. 困ったときは（FAQ）

「AI判定に失敗したため未分類に追加しました」と出る

通知に理由が書かれています。よくある原因は次のとおりです。

  • APIエラー (HTTP 400/401/403)：API キーが正しくない、または権限がありません。設定画面でキーを確認し、「接続テスト」を押してください。
  • APIエラー (HTTP 429)：短時間に使いすぎ、または無料枠の上限です。しばらく待ってから再度実行してください（自動で数回やり直しています）。
  • 通信エラー：ネットワークに接続できていません。
  • AIの応答がブロックされました：ページの内容が AI の安全フィルターに引っかかりました。そのページは手動で振り分けてください。

詳しい記録は、設定画面の「④ 動作ログ」で見られます。

未分類ばかりになる
  • まず「① フォルダ解析」を実行してください。説明文がないと、AI が判断できません。
  • フォルダ名が「その他」「メモ」のように内容を表さないと、AI は選びにくくなります。
  • 確信度が 60% 未満のときは未分類にします。「未分類」に溜まったものは、一括整理（②）で仕分けられます。
通知が出ない・ボタンが出ない

OS の通知設定で Chrome の通知が許可されているか確認してください。Windows の「集中モード」、macOS の「おやすみモード」がオンだと通知が出ないことがあります。通知のボタンは OS によっては表示されません（その場合は、ブックマークの管理画面で操作してください）。

ショートカット Alt+Shift+B が効かない

他の拡張機能と競合すると、割り当てられません。chrome://extensions/shortcuts を開き、この拡張機能の「現在のページを最適なフォルダへブックマーク」に好きなキーを設定してください。

タブを右クリックすると、ページの概要が読み取れないようだ

ブラウザの仕様で、タブを右クリックしたときは、ページの内容を読めないことがあります。その場合は、タイトルと URL だけで判断します。ページの上で右クリックすると、概要（meta 情報）も使えます。

一括整理の結果を取り消したい

適用後、設定画面の「② ブックマークの再カテゴライズ」に「↩ 元に戻す」が表示されます。直前の1回分を、元のフォルダ・位置に戻せます。それ以前の適用は取り消せません。

右クリックメニューに、フォルダが並ばない

設定画面の「右クリックメニューのクイック保存先」でフォルダにチェックを付け、「クイック保存先を保存」を押してください（最大5件）。

API キーを変えたい・消したい

設定画面のキー欄を書き換えて「設定を保存」を押します。消すときは、欄を空にして保存してください。

Gemini 以外の AI（LiteLLM Proxy、社内サーバー等）を使いたい

設定画面の「AI プロバイダ」で「OpenAI 互換エンドポイント（LiteLLM Proxy 等）」を選び、エンドポイントURL・モデル名・API キーを入力して保存してください。手順は AIプロバイダとAPIキーの用意 を参照してください。保存時に、入力したアドレスへのアクセス許可を Chrome が確認してきます。

OpenAI 互換エンドポイントを選んだら、保存できない・エラーになる
  • 「エンドポイントURLを入力してください」「モデル名を入力してください」：どちらも空欄にはできません。
  • 「このエンドポイントへのアクセス許可が得られませんでした」：Chrome の許可ダイアログで「拒否」を選んだか、閉じてしまった場合に出ます。もう一度「設定を保存」を押し、今度は「許可」を選んでください。
  • 接続テストで失敗する場合は、エンドポイントURLの綴り（http:// や https:// から始まっているか）、モデル名（サーバー側のエイリアスと一致しているか）、キーを見直してください。
LiteLLM Proxy 等に切り替えると、判定の精度や挙動は変わる？

プロンプトの内容は Gemini でも LiteLLM 経由でも同じです。ただし、接続先のモデルによって判定の癖や精度は変わります。また、一部のサーバーでは「必ずこの形式のJSONで答えて」という指定（Structured Outputs）への対応が弱いことがあります。その場合でも、本拡張機能は返ってきた値を必ず候補一覧と照合してから使うため、想定外の値が来たときは安全側（未分類・現状維持）に倒れます。
